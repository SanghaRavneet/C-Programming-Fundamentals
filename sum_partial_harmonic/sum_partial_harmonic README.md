Sum Partial Harmonic

Calculates the sum of the first n terms of the harmonic series.

Formula

The calculation is:

1 + 1/2 + 1/3 + ... + 1/n
Function
double sum_partial_harmonic(int n);
Example

For n = 3:

1 + 1/2 + 1/3 ≈ 1.833333

For values less than 1, the function returns 0.0.
