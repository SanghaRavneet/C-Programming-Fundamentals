# C Programming Fundamentals

A collection of small C programs demonstrating fundamental programming concepts, mathematical problem solving, modular programming, input validation, and documentation.

## Overview

This repository contains eight C programming exercises developed as part of my Computer Science coursework. Each exercise focuses on solving a specific programming problem while applying fundamental concepts in C.

The programs are organized into individual directories, with implementation files (`.c`) separated from their corresponding header files (`.h`).

## Concepts Demonstrated

* C programming fundamentals
* Functions and function prototypes
* Header files and modular program design
* Conditional statements
* Loops and iteration
* Integer and floating-point arithmetic
* Mathematical calculations
* Input validation and error handling
* Boolean logic
* Standard C libraries
* Code documentation

## Projects

| Project                                        | Description                                                         | Key Concepts                                             |
| ---------------------------------------------- | ------------------------------------------------------------------- | -------------------------------------------------------- |
| [Date Convert](./date_convert)                 | Converts a date between DDMMYYYY and YYYYMMDD formats               | Integer arithmetic, validation, functions                |
| [Falling Time](./falling_time)                 | Calculates the time required for an object to fall a given distance | Physics, mathematical functions, rounding                |
| [Feet to Acres](./feet_to-acres)               | Converts an area from square feet to acres                          | Unit conversion, constants, floating-point arithmetic    |
| [Hypotenuse](./hypotenuse)                     | Calculates the hypotenuse of a right triangle                       | Pythagorean theorem, `math.h`, floating-point arithmetic |
| [Leap Year](./leap_year)                       | Determines whether a given year is a leap year                      | Boolean logic, conditionals, modulo                      |
| [Mow Lawn](./mow_lawn)                         | Calculates the time required to mow a rectangular lawn              | Arithmetic, validation, unit conversion                  |
| [Sum Even](./sum_even)                         | Calculates the sum of all even numbers from 2 to `n`                | Loops, conditionals, accumulation                        |
| [Sum Partial Harmonic](./sum_partial_harmonic) | Calculates a partial harmonic series                                | Loops, floating-point arithmetic, accumulation           |

## Repository Structure

Each project contains:

```text
project-name/
├── README.md
├── project_name.c
└── project_name.h
```

The `.c` file contains the implementation of the function, while the `.h` file defines the function interface and documentation.
